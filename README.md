# Buni Palette

Per-project colour palettes for packaging and brand work: collect references, generate harmonies,
match to Pantone, test text on colour, and export to Illustrator.

- `prototype/` — the web prototype (v0.6), React + TypeScript. Its `src/` is the starting point for the Windows app.
- `HANDOFF.md` — decisions so far and what v1.0 must include.
